## 二、拼多多状态：成功运行

```
package       com.xunmeng.pinduoduo
versionName   7.94.0
primaryCpuAbi arm64-v8a          ← 关键，64 位 ARM
前台          ...ui.activity.MainFrameActivity
崩溃日志      无
```

### 关键转折：APK 的 ABI 必须匹配

| 来源 | ABI | 结果 |
|---|---|---|
| 应用宝直链（8.32.0） | `armeabi-v7a` 只有 32 位 | ❌ `INSTALL_FAILED_NO_MATCHING_ABIS` |
| **MuMu 应用中心** | **arm64-v8a**（7.94.0） | ✅ 装上就能跑 |

MuMu 没有 `/system/lib/arm`（32 位 ARM 翻译），只有 `/system/lib64/arm64`。
所以只认 64 位 ARM 的 APK。

**应用中心分发的版本是对的**，比自己去各种网站找 APK 靠谱得多。

### 重要发现

**不登录的话，拼多多把所有商品都当「售罄」处理，颜色/尺码/价格全不给。**

所以必须登录才能读到规格。这不是风控，是登录墙。

## 四、需要你做一步

模拟器现在停在**登录页**（MuMu 窗口在你桌面上）：

```
微信登录
其他方式登录 → 手机号 / QQ / 数字身份
```

**两种方式，你选：**

### 方式一：你直接操作 MuMu 窗口（推荐，最快）

切到 MuMu 窗口 → 点「手机号」→ 输入手机号 → 收验证码 → 登录。
**30 秒的事**，你手机收到的验证码直接输进去。

### 方式二：你把手机号告诉我

我用 ADB 帮你输手机号，验证码到了你告诉我，我再输进去。

（数字用 `adb shell input text` 能输，中文不行。）
