## 一、先纠正一个判断：你截图里那个工具，本来就不做你要的事

截图上有三行字，每一行都在说同一件事：

1. **「已签署商品复制承诺书，请遵守平台相关规范，使用者请获取授权后再进行商品复制。」**
   → 它把「源商品」限定在你有授权的范围。这不是技术缺陷，是**厂商的合规开关**——走拼多多官方接口/服务市场的工具都必须挂这个声明。
2. **「发布产品时，加价后的价格不得超过原价格的 1.08 倍。」**
   → **这是决定性的**。拼上拼赚差价一般要加 15~30%，8% 根本不够覆盖。这个工具从加价维度上就不可能满足你的核心需求。
3. **失败原因：「当前发布店铺为试用期店铺，每天只允许上货 1 款产品」**
   → 印证了按店铺授权：你 3 个店 = 3 份钱，边际成本不下降。

所以「省钱 + 团队用」这两个目标，购买这条路本来就走不通。**自建的理由从此不是「省订阅费」，是「唯一能做」。**

### 8% 到底是什么

- 走**官方接口的复制商品通道**时，平台/服务市场工具会校验加价比例，1.08 是这条通道上的硬约束。
- 市面上号称「突破加价限制」的私域软件（福德、神笔、星智那批），靠的是**本地接口 / 模拟人工**绕开这条校验——这也正是它们会被判「停止使用未授权第三方软件」、进而进小黑屋的原因。
- 自建如果走 `copyGoodsCommit`（克隆店内已有商品、再改字段），你实际是在用**商家后台自己的复制商品功能**，加价受后台自己的规则约束。

> ⚠️ **这是整个技术路线的第一个未知数，必须实测**：商家后台「复制商品 / 商品搬家」入口，克隆到自己店铺后手动改价，能改到原价的多少倍？会不会在提交时被拦？

## 二、今天就能做的验证（半天出结果，决定后面怎么走）

### 验证 A：加价上限（最高优先级）

```
1. 在拼多多商家后台，挑一个你自己店铺的商品
2. 用后台自带的「复制商品 / 发布相似商品」功能克隆一条
3. 把价格改成原价的 1.5 倍、2 倍，分别提交
4. 记录：提交是否成功 / 报什么错 / 审核是否通过 / 上架后有没有被比价
```

**三种结果，三条路：**

| 结果 | 含义 | 路线 |
|---|---|---|
| 改价能过 | 后台复制功能不受 8% 限制 | 走 `copyGoodsCommit`，最干净，风险最低 |
| 改价被拦 | 后台本身有校验 | 退到模拟人工填表（不走复制，走新建），逐字段填真值 |
| 改价能过但被比价限流 | 通道没问题，是差异化问题 | 主攻「上架前风险打分 + 主图差异化」这两块 |

这一步不做，后面所有设计都是猜的。

### 验证 B：抓包看它调了什么（30 分钟）

你截图那个是 Web 页面，**所有逻辑都在 Network 面板里**，不需要任何逆向工具：

```
1. Chrome 打开那个「产品搬家」页面，F12 → Network → 勾 Preserve log
2. 筛 XHR / Fetch
3. 走一遍完整流程：粘链接 → 解析 → 设置加价 → 发布
4. 重点抓这四类请求：
   ① 商品解析   —— 它用什么源取商品数据（这决定你的采集端）
   ② 图片处理   —— 图片是直链透传还是转存（决定你需不需要图床）
   ③ 发布提交   —— body 结构、字段名、有没有 sign/token
   ④ 失败回执   —— 错误码字典（这是你未来最值钱的资产）
5. 右键任一请求 → Copy → Copy as cURL，存成文件
```

**能拿到 80% 的答案**，包括：它到底调的是官方开放平台 API 还是它自己的中转服务、加价 1.08 是在前端算的还是服务端拦的、类目属性怎么映射。

## 三、Craft Anything 和 REA 到底是什么

### Craft Anything（`storytold/craft-anything`）

纯 Rust 写的开源「净室逆向 + 重建」引擎。给它一个目标（网站 / 桌面程序 / 手机 App / 游戏），走四步：**研究 → 构建 → 检查 → 就绪**。

- **净室模式（默认）**：刻意**不读**原件内部的任何东西——不读代码、不读文件、不读页面源码。只依据"访客能看到的东西"（截图、可见文本、实测布局、颜色、字体）来重建，再拿结果和原件比对收敛。
- **深度模式**：完整工作台，反汇编、伪 C、字符串、hex、调用图、证据链。
- 320 个工具，每个既是 CLI 子命令又是 MCP 工具；纯研究不需要 AI，但"构建"这一步需要本机有一个编码 agent（首选 Claude Code，也用 Codex / OpenAI / Anthropic / OpenRouter / 本地 OpenAI 兼容服务）。
- Rust / MIT+Apache 双协议，Windows/macOS/Linux/FreeBSD 可用。

### REA（`morluto/rea`，npm 包 `rea-agents`）

MCP 形态的逆向工程工具面，**207 个工具 + 6 条引导式工作流**，能分析原生二进制、JavaScript/Electron（含 asar 解包，纯 JS 静态分析不需要额外反编译器）、.NET 程序集、网站。分析在本机跑，结论带证据和局限说明。可复用你已有的 Hopper / Ghidra / IDA / Jadx。

### 你这台机器的实际状态

| 项 | 状态 |
|---|---|
| `dsh-rea-agents` 插件 | 已装 v1.0.8 |
| `rea-agents` 本体 | **未安装** → MCP 服务 disconnected，207 个工具现在调不到 |
| Craft Anything | 未安装 |
| 可用工具链 | `cargo` / `rustc` 有、`docker` 有、`node` 有 → Craft Anything 能装（源码构建或 `docker run`） |
| 编码 agent | `claude` / `codex` 都不在 PATH → Craft Anything 的「构建」步骤暂时没有执行者 |

## 四、判断：能不能用它俩做出相似功能

**能做出"相似的界面和交互"，但那不是你的难点，也不该是第一步。**

拆开看你缺的三块能力：

| 你缺的能力 | Craft Anything 有用吗 | REA 有用吗 | 真正的解法 |
|---|---|---|---|
| ① 采集端：拿商品数据 | ❌ 净室模式看得到商品页长相，拿不到接口 | ◐ 能分析页面 JS，但比抓包慢 | **DevTools 抓包 + 已登录态复现 XHR** |
| ② 发布端：调通上货链路 | ❌ 你要的正是它刻意不看的内部 | ◐ 能读客户端 JS/asar | **验证 A + `copyGoodsCommit` 路径** |
| ③ 界面/交互复刻 | ✅ 强项（净室模式就是干这个） | ❌ | 一个表单 + 列表，自己写更快 |

具体三条判断：

1. **Craft Anything 的净室模式对你是负价值。** 它故意不看内部，而你需要的就是内部（它调什么接口、参数怎么拼、1.08 在哪一层校验）。你要用它的**深度模式**——但深度模式做的事，等价于「抓包 + 读 JS」，用 DevTools 半小时就够。

2. **REA 对你有真实价值，但不在现在。** 两个场景：
   - 那个工具如果是 Electron 客户端 → REA 直接解 asar 读 JS，能一眼看到加价校验和接口结构。**但你截图这个是 Web 页面，as ar 这条路用不上。**
   - 你将来要攻拼多多的 `sign` 加密 / 反爬（移动端 `apiv3.pinduoduo.com` 那条线）→ REA 的 207 工具就有用了。这是后期的事。

3. **顺序错了代价很大。** 现在是「验证加价上限 → 定通道」的阶段。先花两天装 REA、配 Craft Anything，很可能结论和抓包 30 分钟一样：加价被拦，得走模拟人工。工具越重，越容易让人绕开真问题。

**一句话**：这两个工具是「看懂了之后怎么快速造一个」的工具，你现在还卡在「怎么看懂」。而你看懂的成本，只要一次抓包。

## 五、什么时候才值得上这些工具

按优先级排，到点再做：

| 触发条件 | 上什么 | 预期收益 |
|---|---|---|
| 你需要复刻一个竞品的**完整交互流程**（10 个以上页面/状态） | Craft Anything 净室模式 | 省 UI 从零设计的时间 |
| 你要分析某个**客户端软件**（Electron/APK/EXE）的内部逻辑 | REA | 拿到接口结构和校验层位置 |
| 你要攻拼多多**接口签名 / 反爬** | REA 深度模式 | 打开移动端数据通道 |
| 你的工具要做**跨平台**（PDD/淘宝/抖音） | 都不需要，直接写适配器 | — |

## 六、三个必须避开的坑

1. **别用净室模式去"复刻"接口逻辑**——它设计上就不读内部，你会以为做出了一个"看起来一样"的壳，实际一次发布都跑不通。
2. **别指望逆向那个工具绕过 8%**——1.08 是官方复制通道的校验，不是它的产品设计。绕过校验是「换通道」，不是「改客户端」。
3. **拼上拼（抓别人商品）的风险是民事的，不是技术的**——2024 年浙江高院已判「商品数据复制搬运」构成不正当竞争。技术能做到，和做出来之后能活着，是两件事。你在自有店铺之间迁移自己的商品，风险低一个量级；跨到抓别人，就得自己评估。
