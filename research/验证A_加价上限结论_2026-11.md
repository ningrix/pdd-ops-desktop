## 一、结论先行（三条，都和我上一版说的不一样）

1. **1.08 不是那个工具自己加的护栏，是拼多多平台对「拼单价/团购价」的加价限制。** 三家不同厂商的官方帮助文档互相印证，口径完全一致。
2. **限制只锁「拼单价」，单买价平台不做加价要求。** 原文：「单买价：不拼团，单独购买的价格，此价格拼多多不做加价要求，可自由选择加价，但价格需高于团购价。」→ **这是你真正的加价空间。**
3. **超限的处理方式是「自动改成 8%」，不是拒绝提交。** 欢乐逛原文：「超过限价幅度的商品，将自动修改为加价 8%」。所以市面上宣称「突破加价限制」的软件，突破的是**提交时的校验**，平台侧该钳制还是会钳制。

**一句话**：8% 是平台的定价规则，不是软件的开关。自建也绕不过——但你要的利润本来就不该从「突破 8%」来。

## 三、对「后台复制商品」的预判

**预判：后台「发布相似商品」克隆后改价，拼单价超过 1.08 倍会被钳制或判违规；单买价可以拉高。**

推理依据：
1. 平台规则锚在「同款商品的拼单价 vs 源价」，不区分你从哪条通道进来
2. 工具截图那句警告直接说明后台改价也在监管范围
3. 复制自己的商品，平台照样会做同款识别（否则重复铺货就无从判起）

**但必须实测**，因为有一个真实的反例可能：后台原生复制时，源商品就在同店同平台，平台可能不把它当「搬单」而是当「你自己改价建新链接」，此时约束变成比价（流量给低价那条），而不是硬钳制。

这个差别决定了你的产品怎么做，所以脚本已经写好。

## 五、这才是最重要的部分：产品设计要改

我上一版给你的「改价 + 优化提示词」设计，**前提错了**。不是「做一套能加价 15~30% 的公式」，而是要做**三档价格的联合定价**：

```
目标：毛利率 25%
    ↓  反推
拼单价  = min(源拼单价 × 1.08, 能达到目标毛利的价格)   ← 硬上限，自动钳
单买价  = 拼单价 + max(1, 目标毛利缺口)                ← 自由加价的主战场
市场价  = 单买价 × 1.1~1.5                            ← 需 > 单买价
券/活动 = 用满减、立减把「展示价」和「实付价」拉开        ← 真正的利润结构
```

**为什么这个模型比现有工具强**：
- 现有工具只让你填「倍数」和「加减」，然后你要自己算会不会撞 8% 的天花板 —— 撞了就批量失败
- 你这个模型是**从目标毛利反推三档价格**，并且自动把拼单价钳在合规线上，不会失败
- 「优化提示词」的正确形态变成：`"这个类目毛利要到 30%，运费 4 块，包邮"` → LLM 编译成上面这套三档价格 + 券面额 → 人工确认 → 执行 → 回读校验

**这条设计的一个直接好处**：市面上那批「突破加价」的软件是在赌平台不查，你是在**规则内把利润做满**——批量跑一万个商品不会因为价格被钳而大面积失败。对自用和给团队用，这比「能加 30%」值钱得多。

## 六、附：一个绕开 8% 的合规玩法（竞品在用，值得知道）

极速工具箱那套「大额券」结构，绕的正是这个限制：

```
成本 20 元 → 商品市场价标 200 元 → 设「满 200 减 100」券 → 买家实付 100 元 → 毛利 80 元
```

它不去碰「拼单价加价 8%」，而是把**标价**拉高、用券把实付打下来。平台查的是拼单价相对源价的加价，不是你的券结构。

这属于「结构性定价」，不是「突破校验」。你要做的定价引擎，应该把这种结构也纳入模板库。
