## 二、界面做好了

「采集会话」页重做成一屏搞定：

```
采集别人的商品
粘贴商品链接或商品ID，自动读出标题、价格、颜色、尺码，存进采集箱

[ https://mobile.yangkeduo.com/goods.html?goods_id=...   ] [开始采集]
① 打开商品   ② 读规格   ③ 存采集箱          □ 深度读取全部规格
```

- **一个输入框**：链接或商品ID都行，自动提取数字
- **一个按钮**：点完等着，约 40 秒
- **三个步骤灯**：灰→蓝→绿，能看出走到哪一步了
- **结果卡片**：标题、价格、参考价、颜色、尺码，一行行列清楚
- **不用开第二个窗口**：采集在哪都能做，下面是可选的网页浏览器（抓主图用，默认收起）

## 三、现在的两个模式

| | 安全模式（默认） | 深度读取（需勾选） |
|---|---|---|
| 标题 | ✅ | ✅ |
| 价格 / 参考价 / 销量 | ✅ | ✅ |
| 颜色 / 尺码 | ❌ 读不到 | ✅ |
| 会不会下单 | **绝不会** | ⚠️ 个别商品会直接下单 |
| 耗时 | 约 25 秒 | 约 40 秒 |

### 为什么颜色尺码需要"深度"

我把详情页上所有可能的入口都试过了：

| 尝试 | 结果 |
|---|---|
| 点「颜色款式」文字 | 无反应（它只是标题，不是按钮） |
| 点「商品缩略图1~5」 | 只切换主图，不打开弹层 |
| 找「已选 / 请选择」行 | 这个页面上没有 |
| **点「发起拼单」** | **能打开弹层，但单规格商品会直接下单** |

**结论：拼多多没有提供"只打开规格选择器、不下单"的入口。** 唯一能开弹层的按钮，在特定商品上就是下单按钮。

所以设计成：默认不点，需要全规格时你自己勾选并承担风险。

## 四、主图还是得走网页

App 里的商品图在图片缓存里，导出来很麻烦。所以要主图时：

```
点「需要主图？用网页打开这个链接」→ 网页采集一次 → 拿到 detailGallery
```

但记住：**网页端拿不到价格和规格**（服务端打码，实测桌面/iPhone/微信/安卓 UA + 设备模拟全部无效）。
所以完整采集 = App 拿价格规格 + 网页拿图片。两边互补。
