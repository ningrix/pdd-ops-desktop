## 三、跨店上架：还差最后一块

采集箱里的「上架到当前店」现在会返回：

```
error  : 跨店上架还没实现
advice : 跨店需要「在目标店铺新建商品」的能力
         （本店克隆只能克隆本店商品）。采集箱数据已经存好了。
```

如果目标店铺 == 源店铺，会直接拦住：

```
error  : 目标店铺和源店铺是同一个。
advice : 同店上架会在同一个店里产生重复链接。请选择另一个店铺。
```

### 技术路径（下一步）

`copyGoodsCommit` 只能克隆**本店**商品，跨店需要在目标店「从零新建」。可行的做法：

```
① 在目标店克隆一个它自己的商品（任意一条，当骨架）
② 用采集箱的数据包覆盖字段：标题 / 拼单价 / 主图 / 详情 / SKU 规格
③ 保存 → 提交
```

难点是 ② 里的 SKU 覆盖率——目标店骨架商品的规格结构和数据包不一定一致。图片应该没问题（都是 `img.pddpic.com` 的公开 URL）。
