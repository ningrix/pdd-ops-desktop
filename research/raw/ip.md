## 一、硬性筛选规则（先看这一节，再看别的）

### 1.1 绝对不碰（无书面授权即不上架）

| 禁碰对象 | 原因 | 依据 |
|---|---|---|
| 任何**可识别角色形象**的周边（奶龙、咕咕嘎嘎/臭企鹅、第五人格、原神/星铁/绝区零、明日方舟、蛋仔派对、三丽鸥、迪士尼、线条小狗等） | 著作权法上的「复制 + 发行」侵权，与销量大小无关；1688 小卖家已被公证取证起诉 | 见 §三 案例 1、2 |
| 1688/拼多多页面出现「同款」「官方」「联名」「正版授权」但拿不出授权书的商品 | 「同款」= 默认未授权；「官方」若虚假即构成虚假宣传/混淆 | 反不正当竞争法（2025 修订）第 7、9 条（S15） |
| 用 AI 生成「某官方角色/某品牌吉祥物」再印成实物 | 上游 IP 著作权 + 商标 + 消费者误认三重风险；「AI 生成」不是免责理由 | 见 §四、§五 |
| 游戏/动漫角色「二创」商业化（贴纸、吧唧、立牌、挂件） | 权利人只对「个人非营利/小规模」开放二创；企业化、规模化即超出许可范围 | 米哈游诉多摩万事屋 298 万终审案（S4、S9） |
| 品牌变形词、谐音、近似 LOGO（如直接拿「DeepSeek 娘」「ChatGPT 娘」当商品名） | 拼多多 2026-06 治理新规明确禁止「品牌变形词、衍生词、近似 LOGO」；DeepSeek 已在第 28 类（玩具/健身器材）注册商标 | S17、S18 |

### 1.2 需要什么凭证才能做（缺一不可）

| 商品类型 | 必须持有的凭证 | 备注 |
|---|---|---|
| 有 IP 的正版周边（转售/分销） | ①品牌方或授权商出具的**销售授权书**（写明允许在拼多多销售、授权期限、是否允许一件代发）②完整授权链（IP 方→总代→你的供应商→你）③进货发票/合同/发货单 | 只有「供应商口头说正版」不算；授权书要能覆盖「网络销售」和「代发」 |
| 原创 IP（你自己或供应商原创） | ①美术作品著作权登记证书 ②设计源文件/创作时间戳 ③若供应商原创：其出具的排他授权 + 不侵权承诺函 | 登记证书只是初步证据，仍可能被在先权利人挑战 |
| 无 IP 的白牌搞怪/猎奇商品 | ①供应商营业执照 ②不侵犯第三方知识产权的书面承诺 ③上架前自查（不用知名角色轮廓/配色/名字） | 仍需避开「实质相似」——换个颜色但轮廓一样照样侵权 |
| 官方正版二手转售 | ①原始购买订单/发票 ②商品为「该特定复制件」（不得重制）③不得改动商标、不得宣称官方授权 | 适用「发行权用尽」，见 §三 案例 7 |

### 1.3 一句话判断法

> **「这个形象/名字，是不是别人创造、别人靠它赚钱的？」是 → 必须拿到书面授权；拿不到 → 不上架。**
> 「有人卖、没被抓」只是概率，不是合法性。奶龙案被告卖了 993 个、单链接 90 天 2000+ 成交，仍被公证购买 4 只（18.2 元）后起诉判赔（S1）。

## 三、关键案例与来源

### 案例 1（最关键）：奶龙 —— 1688 卖家卖捏捏乐被判赔

- **案号**：（2024）浙 0782 民初 3570 号；**法院**：浙江省义乌市人民法院；**判决日**：2024-03-18；小额诉讼程序，终审。
- **权利人链**：著作权人 **谢承恩**（作品登记号 国作登字-2019-F-00917161，登记日 2019-11-21，2020-01-22 经抖音「奶龙」账号发表）；2022-06-01 起以**独占许可**授权 **第七印象文化传媒（深圳）有限公司** 行使复制权、发行权、信息网络传播权（授权期至 2025-05-30）。
- **侵权事实**：被告在 **1688** 店铺卖「正品小奶龙捏捏乐慢回弹公仔」，单价 3.8 元起、90 天 2000+ 成交；原告代理人下单 4 只实付 **18.2 元**，公证收货、拍照封存（厦门市开元公证处）。
- **认定**：整体卡通形象在外形、设计与颜色搭配上高度相似，构成**实质性相似**；侵害**发行权、信息网络传播权**；无合理使用。
- **结果**：判赔 **2800 元**（含合理开支），案件受理费 275 元由被告负担 155 元。
- **为什么这条最重要**：被告就是「1688 小卖家 + 一件代发式低客单」的典型画像；权利人取证成本极低（买 4 只 18.2 元），判赔虽小但**足以吃掉首轮 300 元预算的 9 倍**，且店铺会被平台记录侵权。
- 来源：S1（判决书全文转载）

### 案例 2：奶龙 —— 抓娃娃机经营者三案（西安新城区法院）

- **时间**：2024-07-16 西安中院官网发布；**法院**：西安市新城区人民法院，三起案件。
- **事实**：三家抓娃娃机经营者未经授权在机器内放置「奶龙」毛绒玩具；当庭比对「外观、颜色、立体效果基本一致」，构成实质性相似。
- **认定**：侵害**发行权**（以出售方式向公众提供作品复制件）；判令分别赔偿经济损失及合理开支（**金额未在通稿披露，待核实**）。
- **启示**：「不是直接卖、只是抓娃娃奖品」也构成发行；「一件代发」中你作为销售者同理。
- 来源：S2（法院官网）

### 案例 3：奶龙 —— 内江中院 2025 年典型案例（生产 + 销售）

- **时间**：2025-04-24 内江日报（内江中院发布三起典型案例之一）。
- **事实**：内江某经营部销售「毛绒奶龙挂件」，红色吊牌指向某品牌管理公司为生产商，足以使消费者误认。
- **认定**：两被告**生产、销售**行为侵害美术作品著作权；判决停止生产销售并赔偿（**金额未披露，待核实**）。
- **启示**：吊牌/店铺招牌上的品牌标识会加重「混淆」认定；一件代发时供应商的吊牌同样会算到你头上。
- 来源：S3（官媒报道）

### 案例 4：臭企鹅 / 咕咕嘎嘎 —— 权利归属「多方叠加」，目前无人能给出干净授权

按时间线（均为媒体/公示转述，非判决，证据等级 B）：

| 时间 | 事件 | 来源 |
|---|---|---|
| 2025 初 | 「咕咕嘎嘎」原为国外婴儿拟声梗；网友与《BanG Dream!》高松灯（企鹅设定）结合，形成「企鹅=咕咕嘎嘎」 | S7 |
| 游戏上线后 | 《明日方舟：终末地》女管理员因黑白黄配色 + 小碎步被玩家代入帝企鹅 | S5、S7 |
| 2026-02-19 前后 | B 站 UP 主「贱兔死顺盖」发布 **AI 生成**的「企鹅服女管理员」Q 版图，声明「100% 由 AI 生成」「可随意用于 AI 视频二创」 | S5、S7 |
| 2026-03 | 该作者转而主张版权，向使用该形象的商家索要 **10% 版权费**，并自行售卖 20 元钥匙扣；商家要求「先和鹰角对接」后谈崩；舆论压力下作者**道歉并放弃主张版权** | S7、S8 |
| 2026-07 | **字节跳动旗下北京字跳网络技术有限公司** 就「咕咕嘎嘎」等网络热梗申请 2D/3D 美术作品著作权登记（中国版权保护中心公示），同批还有「刀盾狗」「香蕉猫」等 | S5、S6 |
| 2026-09 | 北京字跳**集中撤销**「咕咕嘎嘎」「刀盾狗」「香蕉猫」等美术作品著作权登记 | S6 |

**结论（按中高风险处理）**：
1. **权利归属未查明**。至少四方可能主张：鹰角网络（游戏角色原始著作权）、万代/Bushiroad 侧（高松灯企鹅梗上游元素，待核实）、AI 图发布者「贱兔死顺盖」（其已公开放弃主张）、字节（已撤销登记）。
2. **没有任何一方能给你一份干净的、可对抗鹰角的商用授权**。即使 UP 主回来授权，其图仍是《明日方舟：终末地》角色的衍生作品，商用仍需鹰角许可。
3. 该形象周边价格已从 30 元跌到 7 元（S7），热度与价格都在快速衰减，风险收益比极差。
4. 「臭企鹅」在社媒语境中多指此形象（NGA 讨论帖标题将「臭企鹅唱歌的视频」与「咕咕嘎嘎」并称，见 S7 检索结果），**若用户指的是其他企鹅形象，需人工确认（待核实）**。

### 案例 5：游戏二创规模化 = 侵权（米哈游诉多摩万事屋，298 万终审）

- **时间**：2026-06 报道；**法院**：上海知识产权法院二审驳回上诉、维持一审。
- **事实**：多摩万事屋以企业身份、直营+加盟数十家门店，收购同人作品贴自有品牌销售《原神》《崩坏：星穹铁道》《未定事件簿》《绝区零》《崩坏3》周边，涉及 **141 个角色、1500 余款商品**，抽约 40% 代理费。
- **认定**：一审认定著作权侵权 + 不正当竞争；明确「二创许可」边界——权利人允许**个人或社团非营利及小规模营利**使用，企业化、规模化经营**严重超出**许可范围。二审否定其「仅为寄售方」抗辩，认定其为「生产者」。
- **结果**：停止侵权、公开声明消除影响、连带赔偿 **298 万元**。
- **启示**：①「同人/二创」不是免罪符；②「我只是代发/寄售」不能免责——选品、贴牌、定价就会被认定为销售者/生产者；③**一件代发模式下，你就是那个「销售者」**。
- 来源：S4、S9

### 案例 6：AI 生成内容著作权（2023–2026 中国）

| 案件 | 法院/时间 | 结果 | 要点 |
|---|---|---|---|
| 「文生图第一案」 | 北京互联网法院 **（2023）京 0491 民初 11279 号** | AI 图构成**作品**，著作权归用户（原告）；判赔礼道歉 + **500 元** | 提示词设计、参数调整、随机种子修改体现个性化审美选择 → 具备独创性（S10、S11） |
| 「猫咪晶钻吊坠案」 | 北京互联网法院，2025-09-16 公布 | 原告**败诉**：不构成作品 | 原告未提交原始生成过程记录，仅做「事后模拟」，法院认定无同一性/可比性，证据不足（S11） |
| 江苏首例 AIGC 著作权纠纷 | 江苏某法院，2024-04 起诉，2025-03 报道已生效 | 认定有独创性的 AIGC 图构成作品并判赔；同时认定「平面到立体」的实体装置不侵犯复制权 | **判赔金额抓取乱码，待核实**；（S12，B 级） |

**结论（对卖家的实际意义）**：
1. **「AI 生成」≠ 无主、≠ 可自由商用**。它可能构成作品（归提示词作者），也可能因举证不能而不构成作品——但**两种情况下都不影响上游 IP 权利人向你主张侵权**。
2. 你自己用 AI 生成「很像某角色的图」→ 侵犯上游角色著作权；你用 AI 生成完全原创的图 → 想维权需保存**原始生成过程记录**（提示词、参数、时间、账号），事后补做无效。
3. AI 图还可能因「与他人输出相同」而不具排他性（DeepSeek 协议 4.4 明确可能向不同用户输出相同/相似内容，S13）。

### 案例 7：发行权用尽与合法来源抗辩（正版转售的边界）

- **发行权用尽原则**（最高法知识产权法庭，2025-06-30 报道）：著作权人将作品原件/复制件首次合法投入市场后，对该特定复制件的再次发行无权控制；买受人支付合理对价后有权自用或转让他人。该案首次明确**计算机软件**可适用发行权用尽（芯片与配套软件「一把钥匙一把锁」）。（S21）
- **合法来源抗辩**（《著作权法》第 59 条 + 最高法知识产权民事诉讼证据规定第 4 条）：发行者能证明**合法购货渠道、合理价格、直接供货方**，可推定不知情、**免除赔偿责任**；但**不能免除停止侵害**（仍须下架、销毁）。（S22）
- **对周边的适用条件**：
  1. 转售的必须是**正版复制件**（官方生产、经权利人许可投入市场），不能是仿制品；
  2. 必须是**该特定复制件**，不能是「照着官方图自己印」；
  3. 不得改动商标、包装、防伪标识，不得去掉版权标识；
  4. 不得宣称「官方授权/官方店铺」（你只是转售者）；
  5. 必须保留订单、发票、支付记录——否则连免赔都做不到。
- **不适用**：把官方图印在自制商品上（复制 + 发行）、拆解正版商品再加工、批量生产「同款」。

### 案例 9：第五人格等游戏周边的官方授权路径

- **官方周边出品**：《第五人格》官方正版授权周边由 **网易乐谷** 出品，渠道为「网易乐谷小程序 + 线下门店 + 网易乐谷线上平台 + 其他授权线下渠道」通贩；八周年首发周边采用「小程序预约 + 线下提货」（2026-05 上海）。（S24）
- **IP 授权主体**：国际授权业协会《IP 物语》2026-01-20 显示，网易游戏（授权企业登记为**杭州网易严选贸易有限公司**）开放《第五人格》**商品授权（全品类）**、联合推广、品牌联名，合作周期 1 年；曾合作品牌含食验室、旺仔等。（S23）
- **结论**：
  1. 正版周边只能从官方/授权渠道进货，且**授权是按批次、按品类、按渠道谈的**；
  2. 个人卖家 300 元预算 **不可能** 拿到网易的 IP 商品授权（需企业资质、授权金/保底、品类规划）；
  3. **未查到《第五人格》面向公众的「二创商用许可/同人周边授权规则」**（待核实）→ 按「默认禁止商用」处理；
  4. 正版转售可以，但必须保留官方购买凭证，且不能自称「官方授权店」。

## 五、对首轮 300 元验证的影响（3–5 条）

1. **四个候选 IP 方向（奶龙、臭企鹅、AI 娘、第五人格）在首轮应全部排除。** 300 元预算拿不到任何一份有效授权（网易 IP 商品授权需企业资质 + 授权金/保底；鹰角/第七印象同理），而无授权售卖是**行为本身违法**，不是「被抓到才算」。奶龙案里 1688 卖家单链接卖了 993 个、判赔 2800 元 = 首轮预算的 9 倍（S1）。

2. **首轮唯一安全区是「无 IP 附着」的猎奇萌系/抽象搞怪白牌商品**，但必须做「实质相似」自查：不用任何知名角色的轮廓、配色组合、标志性配饰、名字/谐音。抽象梗只能做**纯文字/表情**类（如拟声词、通用网络用语），且避开平台 2026-06 新规禁止的「品牌变形词、衍生词」。

3. **一件代发不会转移侵权责任。** 你是销售者（甚至被认定为生产者），平台先下架、扣保证金、冻结提现，权利人再起诉；供应商跑路你兜底。所以「先卖热门周边积累现金」这个策略，**在最热的那几个 IP 上恰恰是风险最高、最不该做的**。

4. **如果一定要做 IP 相关，唯一合规路径是「正版转售」**：从官方渠道（如网易乐谷、品牌天猫旗舰店、官方线下店）买入正版，保留订单/发票，加价转售，不宣称官方授权、不改动商品。但 300 元本金 + 官方周边单价高/限量，实际起量困难，建议作为第二轮验证方向。

5. **合规成本要计入首轮预算**：即使卖白牌，也建议花 0 元做三件事——①上架前用「中国版权保护中心 + 中国商标网」粗查关键词；②向供应商索要 A/B/C 清单材料并存档；③商品页不写「官方/同款/联名/正版」（写了就要举证）。这三件事不花钱，但能挡掉大部分投诉。
