### 红线检测（7 条，源码级）

应用渲染层无 type="module"；style.css 无 backdrop-filter（按 CSS 声明判定，排除注释）；#pane-browser 祖先无 transform/filter；四份样张全部无 module / 无 backdrop-filter / 无 filter: 声明、全部带 data-zcode-design 标记。

> 检测器第一版误报 3 条：把注释和说明文字里的「backdrop-filter / filter」字样当成了声明。修正为「仅 <style> 块内、剔除注释后按 `filter:` 声明判定」——这类检测器自身的假阳性也要过一遍人工，否则会逼着人改掉正确的代码。

## 二、8.4 业务语义 bug 复盘（本轮最重要的一条）

**现象**：损失剔除流演成「实收 1,557.75 − 退款 7,054.25 = 净额 −5,496.50」——负数，与商品贡献表中该商品**盈利**（扣费后 357.95）自相矛盾。

**根因**：不是代码错，是**业务口径错**。贡献表里的「实收 1,557.75」已经是剔除退款后的净数；拿净数再减一遍退款 = 重复扣减。

**修正**：「损失剔除」的正确叙事是 **成交 GMV 8,612.00（推导值 = 净实收 + 退款合计）→ 退款逐笔飞离、GMV 滚动递减 → 净实收 1,557.75 定格**。三个数字与贡献表完全自洽，动画终值就是贡献表的实收。

**沉淀为规则（供 AGENTS §1.3 吸收）**：做资金类演示/统计前，先确认每个数字在业务口径里的位置（GMV / 净实收 / 退款合计），推导值要标注推导来源；「看着合理的负数」要跟既有报表交叉核对一遍再上台面。

## 三、调研沉淀（三轮样张的方法论收口）

### 3.1 技术栈结论
vanilla + 双层 CSS token（全局 --u-* + 组件级），不引框架——构建型栈（Vue3+Vite+TDesign，同类项目主流）被三条硬约束排除（file:// 加载禁 module / 无构建步骤 / 离线可用）。设计质量来自 token 纪律 + 动效刻度纪律，而非组件库。

### 3.2 动效刻度（全站唯一来源，已落地到全部样张）
120ms（悬浮/按压/滑块跟随 · ease-std）｜220ms（展开 decel / 缩回 accel 成对）｜280ms（弹层进场 decel）｜420ms（弹簧强调，对齐现行 rt-pop）。一致性三律：退场比进场快 ×0.7；同一手势一条曲线；同屏并发 ≤2。

### 3.3 高性能假毛玻璃配方
三层叠加（半透明深底 + inset 1px 顶光 + 135° sheen）+ 三档透明度（slim .55 / panel .72 / overlay .86），零 backdrop-filter / 零 filter；只允许出现在 #pane-browser 的**非祖先**层。

### 3.4 社会心理学定律 → 动效映射（本轮新增）
| 定律 | 动效 |
| --- | --- |
| 损失厌恶 / 前景理论 | 阈值跨越单次强调；损失聚合；红=钱不=状态 |
| 蔡格尼克 | 未闭环慢脉动（2.4s）≠ 忙碌快呼吸（1.15s） |
