# 「主图优化」效果演示 + 命名建议

> 2026-11-18 03:00 ｜ 全部为本机真实运行结果，代码在 `tools/imgtool/`

---

## 一、你说得对：这个词太笼统

「主图优化」听起来像一句口号，用户不知道它能干什么、花这个钱值不值。

**「AI 修图」也不准确** —— 我们做的四件事里，只有一件勉强算"AI 生成"，
其余三件是**增强**不是**生成**。叫「AI 修图」会让用户期待"换个背景、换个模特"，
那是另一套东西（生成式），我们没做。

### 我的建议：拆成动词，一个功能一个名字

```
图片工具
├─ ① 超分放大      4x 提升清晰度（源图太小才需要）
├─ ② 去水印 / 去标  清掉友商 logo、水印、贴标
├─ ③ 加水印        品牌标 / 防盗平铺 / 卖点条
├─ ④ 白底化        抠背景、统一纯白
└─ ⑤ 尺寸规整      裁剪居中、按平台规格输出
```

**好处**：用户一眼知道每项干什么，可以按需勾选，不用买一整套。

样张在 `交付样张/主图处理演示_2026-11-18/`。

### 演示 1：超分 —— 像素级对比（最有说服力）

```
原图取 100x100 小块 → 两边都放大到 600x600
左：直接撑大       → 一片马赛克，看不出是什么

```

**这是真效果，不是锐化滤镜。** RRDBNet 在重建结构，不是插值。

### 演示 2：超分 —— 细节区对比

```
400x400 原裁切 → 两边都显示到 620x620
左：双三次插值（普通放大）   → 网布糊成一片，边缘发软
右：4x 超分后缩回同尺寸       → 每根线都分得开，鞋底纹路有立体感
```

| 模式 | 效果 | 用途 |

## 三、演示暴露的两个真问题（都已修）

### 问题 1：PIL 9.5.0 在这个环境下画字会**直接崩溃**

```
进程退出码 0xC0000005（ACCESS_VIOLATION）
连 draw.text() 都挂，不只是 textbbox
```

**修法**：升级 Pillow `9.5.0 → 11.3.0`，实测正常。

顺带卸掉了 `simple-lama-inpainting`（它要求 `pillow<10`，会把 Pillow 拖回去）。

### 问题 2：第一版水印在**白底主图上几乎看不见**

这是拼多多主图的典型情况 —— 白底产品图占绝大多数，
**白色水印压上去等于没加**。第一版演示就是这样，角标和平铺都发虚。

**修法**：加自适应取色 `auto_color()`

```python
# 取文字背后区域的平均亮度，白底 → 深色字，深底 → 白色字
return dark if _luma_mean(img, box) >= 150 else light
```

修完后的效果：白底上自动出深灰字，清晰可读。
对比图里能直接看出差别（`对比_水印三模式.jpg`）。

## 四、速度实测（这是必须知道的成本）

| 任务 | 尺寸 | 耗时 |
|---|---|---|
| 水印 · 角标 | 1200x1200 | **36 ms** |
| 水印 · 平铺 | 1200x1200 | **178 ms** |
| 水印 · 卖点条 | 1200x1200 | **19 ms** |
| 超分 4x | 400x400 → 1600x1600 | **21 秒** |
| 超分 4x | 1200x1200 → 4800x4800 | **174 秒（2.9 分钟）** |

**结论：水印白菜价，超分很贵。**

### 所以超分不该无脑用

拼多多主图要求 480px 以上，而你现在采集到的图普遍是 800~1200px ——
**已经够用，不需要超分。**

超分真实需要的场景只有：

| 场景 | 值不值 |
|---|---|
| 源图只有 400~600px（盗图/截图），要放大到 800+ | ✅ 值 |
| 想在 1200px 图上裁一块当特写图 | ✅ 值（只超分那一块） |
| 原图已经 1200px，只是想要"更好看" | ❌ 不值，3 分钟/张 |

**我的建议**：超分做成**按需触发**，默认关闭。
界面上标出「此图 1200px 已达标，无需超分」这种提示。

## 七、我的建议

**先把演示给你看，你判断值不值，再决定做不做剩下的。**

如果你觉得超分效果有用（对比图摆在那），那就继续做去水印和白底化；
如果觉得"我现在的图本来就够清晰，不需要超分"，那**超分这项可以砍掉**，
省钱省时间，只做水印 + 检测。

**这种判断必须你来做**，因为只有你知道你的货源图普遍是多少分辨率。

## 附：怎么自己复现

```bash
# 水印
python -m tools.imgtool watermark --in a.jpg --out b.jpg \
  --text "山野户外旗舰店" --mode corner --pos br --opacity 0.55

# 超分（建议只对小块用）
python -m tools.imgtool upscale --in a.jpg --out b.jpg --scale 4 --tile 512

# JSON 输出便于程序调用
python -m tools.imgtool watermark ... --json
```
