## 一、格式拿到了

接口：

```
POST /glide/forward/cabernet/mms/sizespec/action/post
```

完整请求体（从你「lu鸭绒羽绒服」那个商品的编辑页保存时抓到的原文）：

```json
{
  "content": {
    "meta": {
      "groups":   [{"id": 1}],
      "elements": [{"id": 10004}]
    },
    "records": [
      {"values": {"1": "10", "10004": "175～185"}},
      {"values": {"1": "8",  "10004": "170～180"}},
      {"values": {"1": "6",  "10004": "165～175"}},
      {"values": {"1": "4",  "10004": "160～170"}},
      {"values": {"1": "2",  "10004": "155～165"}}
    ],
    "pic_url": "https://img.pddpic.com/mms-material-img/2026-11-16/xxx.png"
  },
  "status": 0,
  "class_id": 7,
  "id": 354341256
}
```

### 结构解读

| 字段 | 含义 |
|---|---|
| `content.meta.groups[]` | **列定义**（`id:1` = 尺码列） |
| `content.meta.elements[]` | **参数列定义**（`id:10004` = 推荐身高，平台固定 id） |
| `content.records[]` | **数据行**，`values` 用列 id 当 key |
| `status` | 0 = 启用 |
| `class_id` | 尺码表类别（7 = 服装类；鞋类应该是别的值） |
| `id` | 已有尺码表的记录 id；新建时不传 |

正好对应你说的 Lululemon 那种 `2/4/6/8/10` + 身高 的标法。
