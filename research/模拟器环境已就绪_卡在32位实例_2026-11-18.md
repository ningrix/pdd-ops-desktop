## 二、卡在哪：PDD 一启动就崩

```
Fatal signal 11 (SIGSEGV) in com.xunmeng.pinduoduo
ABI: 'x86'
#00 pc 0024360e  /system/lib/libhoudini.so
```

**`libhoudini.so` 是 Intel 的 ARM→x86 翻译层。**

崩溃发生在翻译层里，意思是：拼多多的原生库（.so）在这个 32 位 x86 环境里跑不动。

### 根因

winget 装的 BlueStacks 默认实例是 **Nougat32 = Android 7.1.2 / 32位**：

```
ro.build.version.release  7.1.2
ro.build.version.sdk      25
ro.product.cpu.abilist    x86, armeabi-v7a, armeabi     ← 只有 32位 ARM，没有 arm64-v8a
```

拼多多现在的版本主要靠 **arm64-v8a** 原生库（安全模块、图片处理），
32 位的 houdini 翻译不了，直接段错误。

---

## 三、解法：建一个 64 位实例

BlueStacks 的 64 位镜像（Android 9/11/13）支持 `arm64-v8a`，PDD 的原生库能原生运行。

### 需要你点三下（CLI 不支持，只能 GUI）

```
① 开始菜单打开「BlueStacks Multi-Instance Manager」（多开管理器）
② 点右下角「实例」→「新建实例」
③ 选 Android 11 或 Android 13（64位），点「下一步」
   → 会下载镜像，约 1.5~2 GB（会自动落到 D 盘，因为整个 ProgramData 已经是联接）
```

建好后告诉我实例名，我立刻：

```
adb connect 127.0.0.1:<新实例端口>
adb install pinduoduo_8.32.0.apk
adb shell monkey -p com.xunmeng.pinduoduo -c android.intent.category.LAUNCHER 1
```

## 四、我的判断：可能有更快的一条路

**AMD CPU + BlueStacks 的 ARM 翻译，兼容性一直是弱项。** 你这台是 Ryzen 7 8845HS。

如果 64 位实例还是崩，建议换 **MuMu 模拟器 12**：
- 对 AMD 优化明显更好
- ARM 兼容层（MuMu 自己做的一套）对国内 App 适配更广
- 自带「机型模拟」，对风控更友好
- 免费

代价：要重新装一次（约 10 分钟），同样可以装到 D 盘。

### 而最稳的其实是真机

| | 模拟器 | 真机 + ADB |
|---|---|---|
| 兼容性 | ⚠️ 翻译层可能崩（现在就崩了） | ✅ 原生 |
| 风控 | ⚠️ 仍有风险 | ✅ 最低 |
| 成本 | 0 元 | 一台旧安卓机 |
| 速度 | 慢（翻译层） | 快 |

**如果你手边有闲置的安卓手机，插上 USB 开「USB 调试」，比折腾模拟器快得多，而且风控风险最低。**

## 五、顺便：真人化工具已经写好了

`tools/adb-human.js` —— 跟用哪个模拟器无关，随时能用。

它解决的问题：ADB 的 `input tap x y` 是**瞬时、精确到像素、间隔固定**的，
这三件事本身就是最强的机器人特征。真实手指是：

| 真实手指 | `input tap` | 工具里怎么处理 |
|---|---|---|
| 落点有偏差 | 精确到像素 | 在元素框内随机偏移，避开边缘 18% |
| 按下有 50~120ms | 0ms 瞬时 | 改用 `input swipe` 微距短时（60~130ms） |
| 屏幕上有手抖 | 完全静止 | 坐标加 ±6px 抖动 |
| 操作间隔不规律 | 固定间隔 | 对数正态分布（中位 1.6s，尾部 4s） |
| 滑动有加减速 | 匀速 | 分 2~4 段，每段速度不同 |

命令：

```bash
node tools/adb-human.js status          # 连接状态
node tools/adb-human.js fingerprint     # 检查模拟器指纹泄露
node tools/adb-human.js dump            # 导出界面文字
node tools/adb-human.js browse 3        # 像人一样浏览（滑 3 次，带停顿）
node tools/adb-human.js tap-text 黑色    # 按文字找元素并人类式点击
```

**注意**：它只能伪装「行为层」。深层指纹（qemu 属性、传感器是否存在、电池曲线）
ADB 改不了 —— 那些只能靠真机。
