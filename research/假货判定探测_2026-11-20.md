# 假货判定探测记录（2026-11-20）

> 目标：找到拼多多商家后台「商品是否被判定为假货」的可读信号，做成应用内检测。

## 1. 用户观察到的唯一入口

店铺营销 → 营销工具 → 下单送赠品 → 创建 → 选择主商品。
被判定假货的商品在该弹窗里显示：

> 不可选原因：该商品被判定为假货，暂不支持创建。详见《拼多多假货处理规则》等平台协议及规则。

## 2. 探测到的页面与路由

- 营销工具页：`https://mms.pinduoduo.com/tool`
- 下单送赠品入口：`/kit/freebie?tool_full_channel=10921_77275`（点击卡片时 `window.open` 该地址）
- 活动管理页：`/kit/freebie/manage?tab=activity_manage`
- 页面加载时调用的两个接口：
  - `POST /bordeaux/mms/gift/query_mall_has_qualification`
  - `POST /bordeaux/mms/gift/query_mall_has_enrolled_event`

## 3. 已验证可用的接口（店铺级）

```text
POST https://mms.pinduoduo.com/bordeaux/mms/gift/query_mall_has_qualification
body: {}
```

返回：

```json
{ "has_qualification": 0,
  "reject_reason": "店铺存在销售假货等违规情形，暂不支持参与活动。详见《拼多多假货处理规则》等平台协议及规则。" }
```

三店实测（2026-11-20）：

| 店铺 | has_qualification | reject_reason |
| --- | --- | --- |
| 阿泽made | 0 | 店铺存在销售假货等违规情形… |
| 布丁2 | 1 | 空 |
| 阿泽高端made | 0 | 店铺存在销售假货等违规情形… |

结论：**该接口就是店铺级假货判定的权威读法**，无需打开弹窗。

## 4. 商品级接口（已拿到）

从 `https://mms-static.pddpic.com/kit/static/js/9.c7751fc0.chunk.*.js` 里 grep 出全部 gift 接口，其中商品列表接口是：

```text
POST /bordeaux/mms/gift/query_event_goods_list
body: { "page": 1, "size": 50 }
```

返回：

```json
{
  "total": 4,
  "goods_display_info_list": [
    {
      "goods_id": 1030237518192,
      "goods_name": "山行2代 GTX户外登山鞋…",
      "hd_thumb_url": "https://img.pddpic.com/…",
      "sku_group_price": [29222, 29222],
      "quantity": 1312,
      "can_enroll_event": 1
    },
    {
      "goods_id": 1031051901810,
      "can_enroll_event": 0,
      "cant_enroll_reason": "该类商品被判定为假货，暂不支持创建。详见《拼多多假货处理规则》等平台协议及规则。"
    }
  ]
}
```

判据：`can_enroll_event === 0` 即被平台判定不可参加活动，`cant_enroll_reason` 给原文原因（假货时就是那句）。

**注意参数名**：必须是 `{page, size}`。`page_size` / `page_number` / `size` 混用时接口抛错（`THROW [object Object]`），只有 `{page, size}` 正常返回。

分页：`page` 从 1 递增，返回不足 `size` 条即结束；`total` 是总数。

## 5. 已落地的能力

- 主进程 `risk:goodsCheck`：为每个店铺开隐藏窗口加载 `/kit/freebie`，
  逐页调用 `query_event_goods_list`（`{page, size:50}`），汇总 `can_enroll_event=0` 的商品，
  带出 `goods_id / goods_name / hd_thumb_url / quantity / cant_enroll_reason`。
- 渲染层新增左侧导航「商品检测」页（与商品列表/采集箱同级），表格列为：
  **图 / 商品 ID / 商品名 / 原因**，并按店铺分组：每组一行标题
  `店铺名 · N / M 个被判定`，下面是该店的商品行。
  原因只显示第一句（「该类商品被判定为假货，暂不支持创建」），完整原文放在 `title` 悬停。
- 检测入口只有一处：商品检测页右上角「开始检测」。左侧栏不再放检测模块。
- 实测（2026-11-20）：22 个商品中 20 个被判定，阿泽made / 布丁2 / 阿泽高端made 三店约 29 秒完成，
  表格无横向滚动，20 张缩略图全部加载成功。
- 店铺级「假货检测」已按用户要求移除，只保留商品级。
