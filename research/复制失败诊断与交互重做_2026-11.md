## 一、复制失败：接口是好的，问题在别处

### 用调试浏览器直连同一家店，连做 3 次全部成功

```
idx 0  goods_id 1028820098943  copyedCheck=false  → 新草稿 206419410018 / goods 1030480918842  ✅
idx 1  goods_id 1027027920495  copyedCheck=false  → 新草稿 206419414467 / goods 1030481322148  ✅
idx 2  goods_id 1027025166853  copyedCheck=false  → 新草稿 206419418931 / goods 1030480954530  ✅
```

同一家店、同一批商品、同样的 `create_by_sn → copyGoodsCommit`，在独立的调试浏览器里 3/3 成功。所以**不是接口不通，也不存在"6 个商品的店不能复制"这种限制**。

### 应用里失败的真实原因：登录态丢了

我查了应用的会话目录：

```
%APPDATA%\pdd-ops-desktop\Partitions\      ← 不存在
%APPDATA%\pdd-ops-desktop\Network\Cookies  ← 不存在
```

**整个应用没有任何 cookie 落盘。** 原因是调试期间我反复用 `Stop-Process -Force` 强杀 Electron —— Chromium 的 cookie 是异步刷盘的，硬杀就会丢掉刚扫码登录的会话。

所以你点的「复制」其实是在**未登录状态**下打的接口，被平台拒绝；而我旧代码只显示「copyGoodsCommit 失败」，把 `error_code` / `error_msg` 全吞了，看起来像是商品本身有问题。

### 已修三处

| 问题 | 修法 |
|---|---|
| 强制结束丢登录态 | 加 `before-quit` → `session.flushStorageData()`，退出前主动落盘 |
| 错误被吞 | `copyGoods` 现在返回 `detail`（平台原始 `error_code` / `error_msg`），界面直接显示 |
| 失败无提示 | 结果卡片写明原因；日志打出完整返回 |

**你需要做一次**：重新登录一次（扫一次码），之后正常关闭窗口就会保留登录态。

## 二、交互重做：从「填索引」改成「点按钮」

你说得对，原来那个「复制第几条（索引）」是新手的噩梦。整个流程改成这样：

### 左栏只剩三步

```
① 店铺          [＋ 添加店铺]
                  A-羽绒服

② 选商品        [读取本店在售商品]
                  读出以后，在右边「商品列表」里
                  点某一行的「复制」按钮就能开始

③ 最近一次的结果
[ 草稿已创建  成功 ]
  标题      lu鸭绒羽绒服…
  图片/SKU  14 张 / 45 个
  拼单价    347.42
  草稿号    206419410018
```

### 商品列表每行一个「复制」按钮

不用记索引，不用回左栏，看到想复制的商品直接点。

### 点「复制」弹出一张配置卡

```
复制这个商品
┌──────────────────────────────────────────┐
│ [图] lu鸭绒羽绒服五格露泡多巴胺女士…      │
│      拼单价 330.88 ｜ 单买价 363.97 ｜    │
│      45 个 SKU ｜ 库存 1008              │
└──────────────────────────────────────────┘

新商品标题  [ lu鸭绒羽绒服…-新款 ]     ← 自动预填，加后缀
            改一下标题，能降低和原链接的重复度

改价倍数    [ 1.05 ]
            ┌────────────────────────────────
            │ 拼单价 330.88 → 347.42（+16.54 元）
            │ 单买价 363.97 → 382.17
            └────────────────────────────────

☑ 复制后顺便改价（会多花约 15 秒）

                    [取消]  [开始复制]
```

- **标题自动预填**：原标题 + `-新款`
- **改价实时预览**：填倍数立刻算出新价格和涨幅，不用心算
- **改价可选**：勾掉就只复制，省 15 秒

### 执行时看到的是进度，不是一坨日志

```
[■■■■■■■□□□]  55%
草稿已建：图 14 张，SKU 45 个
正在改价（约 15 秒）...
改价成功：拼单价 347.42
完成
```

失败时直接写平台原因，例如：

```
复制失败：copyGoodsCommit 被平台拒绝（{"error_msg":"商品已在草稿箱","error_code":2000000}）
```

## 三、顺手修的一个隐患

所有弹窗（添加店铺、复制配置）现在都会**先摘掉原生浏览器视图**再弹出。

原因：`WebContentsView` 是原生层，永远盖在 HTML 之上。之前的现象就是你看到的——遮罩让左栏变暗、对话框被浏览器盖住、只有浏览器能点，看起来像卡死。

## 五、你现在要做的

1. 双击桌面「拼多多上货中台」
2. 点 **＋ 添加店铺** → 给个名字 → 在右边扫码登录
3. 点顶部 **检测登录**，看到「登录有效」
4. 点 **读取本店在售商品**
5. 在右边列表点任意一行 **复制** → 弹窗里点 **开始复制**

如果还失败，日志现在会打平台真实错误码，把那行发我就行。

> 关闭应用请用窗口右上角 ✕，不要用任务管理器结束进程 —— 那样会丢登录态。
