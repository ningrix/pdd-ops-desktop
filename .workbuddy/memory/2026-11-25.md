# 2026-11-25

## 打包 Windows 测试版（v0.5.0）

**产物**：`app/dist/pdd-ops-0.5.0-beta-setup.exe`（102M）、`pdd-ops-0.5.0-beta-x64.zip`（131M）、`使用说明.md`。

**选型**：electron-builder 26.18.1（v27 仍 alpha）+ NSIS 向导式 + zip。
用 `electronDist` 指向本地 `node_modules/electron/dist`，跳过 158MB 下载；NSIS 缓存本机已有。

**改动的文件**：
- `app/main.js`：`pickDataDir()` 三级探针（%APPDATA% → %LOCALAPPDATA% → exe 同级）；打包态默认开 CDP 9333；
  `trace()` 在打包态额外写 exe 同级 `boot.log`。
- `app/lib/imgtool.js`：`ROOT` 打包态取 `process.resourcesPath`（不引入 electron 依赖）。
- `app/package.json`：version 0.5.0、build 字段、dist 脚本。
- `app/build/icon.ico`、`app/build/start-compat.bat`。
- `app/renderer/index.html`：标题栏 v0.2 → v0.5 beta。
- `.gitignore`：`app/release/`、`app/dist/`、`app/out-*/`。
- `AGENTS.md`：新增 §10 打包与分发；代码地图补 build/、dist/。

**三个坑（都已记入 AGENTS.md §10）**：
1. **version 不能写 prerelease**：`0.5.0-beta.1` 会让 exe 的 FileVersion 变成非法串，Windows 直接拒绝加载 ——
   零报错、退出码 3、main.js 一行不执行。改成 `0.5.0` 后正常。
2. **本机 shell 注入 `ELECTRON_RUN_AS_NODE=1` + `NODE_OPTIONS=--require=…shim`**：两者都会让 Electron 起不来。
   验证时必须 `env -u NODE_OPTIONS -u ELECTRON_RUN_AS_NODE`，并显式传 `--no-sandbox --disable-gpu`。
   判据是 `boot.log` 有没有 `module start`。
3. **未签名包静默安装被 SmartScreen 拦**：`/S` 返回 0 但零动作（快捷方式建了，文件没落地）。
   手动双击正常。不要用 /S 判断包好坏，用 `7za t` + 手动安装。

**验证结果**：zip 解压 84 文件 → 启动 → `renderer did-finish-load` → 应用已启动；
CDP 截图确认 8 个页签、615 节点、无白屏；调试端口 9333 监听正常。
本机 %APPDATA% 与 %LOCALAPPDATA% 均 EPERM，探针按预期降级到 exe 同级 userdata。

**未验证**：安装包的手动安装流程（需要人点 SmartScreen），只能到目标机验证。
**遗留**：`app/release/`、`app/out-verify*`、`app/out-v4/v5` 被文件锁占用删不掉（已 gitignore）。
