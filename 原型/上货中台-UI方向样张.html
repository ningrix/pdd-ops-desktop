拼多多上货中台 · UI 方向样张（4 个，调研版）

同一屏（资金复盘）、同一份真实数据（2026-11-20 采集，无虚构指标）。每个方向的取舍都挂在调研依据上：苹果 HIG、前景理论 / 损失厌恶、平台-商户信息不对称、TDesign / Ant Design 的 token 体系。技术栈结论见 research/UI方向调研_2026-11-21.md。

全部样张遵守应用硬约束：无 ES module、布局无 transform / filter / backdrop-filter（不碰 #pane-browser containing block）、系统字体、软件渲染友好、离线可用（无运行时 CDN）。

方向 A · 精修现行演进路线 · CSS diff 最小，可直接并入 style.css
依据：HIG「deference」——chrome 压平压暗，数字自己说话；改动只落在层级（主数字加粗、次级弱化、间距节奏 8/12/16 统一）。风险最低，四个方向里唯一可以一次合并的。
方向 B · 对账终端高密度账本 · 等宽数字 · 零装饰
依据：政治经济学——平台与商户的信息不对称是本工具的存在理由，界面立场是「逐笔记清楚平台拿走了什么」；账本式克制（无卡片、无圆角、网格线 1px、等宽数字）让对账成为默认心智。代价：观感冷硬，适合长时间扫数，不适合演示。
方向 C · 经营看板参照点 + 聚合 · 大数字 · 健康摘要条
依据：前景理论——参照点决定框架（末卡「今日净现金流」做强调位），损失聚合（费用聚成「每单扣费 19.96」一个大数，明细退后一档）；Hick 定律——顶部动作收敛为主/次两级。chips 摘要条把「在途售后 27、检测 20/22」这类需要行动的信号前置。
方向 D · 浅色工作台HIG clarity 全量 · 含浅色顶栏（提案）
依据：HIG「clarity」全量——白底、清晰边界、语义色用已过 AA 的浅色组（#0f7a4d / #c0392b / #96601a）。顶栏改浅色是提案：现行自绘窗口按钮本就不依赖 titleBarOverlay，改色只需动 .topbar 两个变量。适合白天长时使用与截屏汇报。
怎么选
四个方向共用同一套 DOM 与 token 结构（换方向 = 改十几个变量 + 少量覆盖规则），可并行试、可混搭（例如 B 的表格密度 + C 的参照点卡）。
A：今天就能并，零风险。B：如果每天开着它对账，选这个。C：如果要看「生意健康度」做决策，选这个。D：浅色主题的完整答案。
迁移路径（软件工程）：先合 token（:root 双层变量，命名对齐 TDesign 的 --td-* 两层式）→ 再合组件级覆盖 → 状态覆盖（空/载/错/密）逐页验收 → 每步跑对比度断言。
